# 배경음 음원

여기 `bgm.webm` 과 `bgm.mp3` 를 둡니다. 둘 다 같은 소리이고,
브라우저가 webm(opus) 을 못 열 때만 mp3 로 넘어갑니다.

- 손님이 소리를 켜실 때 비로소 받습니다(`preload="none"`).
  끝까지 안 켜시는 분은 한 바이트도 안 받습니다.
- 두 파일이 다 없으면 `js/sound.js` 가 그 자리에서 소리를 지어냅니다.
  그래서 음원을 빼도 서비스는 그대로 돕니다.
