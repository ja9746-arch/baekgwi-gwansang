# 백귀관상

원안법사(圓安法師)가 얼굴에 새겨진 기운을 읽어, 타고난 그릇과
올해의 흐름을 살피는 관상 서비스입니다.

## 짜임새

```
index.html        화면과 흐름 전부
js/baekgwi.js     백귀 100장 — 이름·한자·그림·성정·경고·처방
js/gungsang.js    십이궁 풀이, 오행형상, 기색, 유년운기부위, 시기, 처방
js/engine.js      사진을 재고 관상을 가리는 엔진
js/saju.js        입춘·절입으로 가른 네 기둥과 십성
js/cross.js       얼굴의 궁과 사주를 맞대는 교차판
js/sound.js       배경음 (파일 없이 그 자리에서 지어냅니다)
img/              키비주얼, 제목, 청동경, 백귀도, 법사 장면, 백귀 100장
```

틀도 빌드도 없는 정적 파일입니다. 그대로 올리면 됩니다.

## 흐름

거울 받기 → 나이·성별 → 거울에 바로 비추거나 사진첩에서 고르기
→ 얼굴을 저절로 맞추고, 자리가 맞으면 선이 금빛으로 섭니다
→ 자세 잡기 의식 → 얼굴 읽기와 판정 요약 → 유년운기로 지난 일 적중
→ 자국 짚기 → 백귀 셋 중 고르기와 뒤집기 → 열두 자리(무료는 가장 좋은 한 자리)
→ 복채 3,990원 → 전부 열람 → 점자리·색·머리 처방 → 백귀도 한 장
→ 총평(할 일 셋·피할 것 둘·시기) → 교차 풀이 9,900원

## 엔진

거울에 비친 얼굴에서 직접 수치를 뽑습니다.

- **재는 것** 삼정의 두께, 얼굴 윤곽의 가로세로비와 하정이 좁아지는 정도,
  색의 치우침(조명 보정 포함), 좌우 밝기 차, 열두 자리의 밝기와 결
- **가리는 것** 오행형상(목화토금수), 기색(청적황백흑), 둘의 상생상극,
  십이궁 트임·반반·막힘, 유년운기부위 1~99세
- **남좌여우** 짝이 있는 여덟 자리는 남자는 몸의 왼쪽, 여자는 몸의 오른쪽을
  본인 자리로 놓고 읽습니다. 성별에 따라 등급이 갈립니다.
- **색 처방** 길색은 나를 생하는 색과 같은 갈래의 색, 꺼릴 색은 나를 극하는 색.
  기색이 그릇을 누르고 있으면 꺼릴 색을 그 기색으로 바꿉니다.

백귀 100장은 열두 궁에 모두 나뉘어 있고, 판정 등급과 얼굴 수치로
골라 섭니다. 같은 사진이면 늘 같은 결과가 나옵니다.

## 사진

올린 사진은 이용자의 기기 안에서만 처리됩니다. 서버로 전송되지 않고
저장되지 않습니다. 판정 결과만(사진 없이) 기기에 적어 두었다가,
다시 오셨을 때 지난번과 견주어 보여 줍니다.

## 사주

생년월일시에서 네 기둥을 셉니다. 해는 입춘, 달은 절입으로 가르고,
시간은 전국 일괄 30분을 당깁니다. 야자시는 일주를 그날 그대로 두고
시주만 다음 날 일간으로 셉니다. 절기는 태양 황경을 직접 셈해 찾습니다.

## 결제

`index.html` 의 `openCheckout()` 한 군데만 갈아 끼우면 됩니다.
성공이면 `true`, 취소·실패면 `false` 를 돌려주면 나머지는 그대로 돕니다.
`DEMO_CHECKOUT = false` 로 바꿔야 실제 결제로 넘어갑니다.

값은 `PRICE` 에 모여 있습니다. `PRICE.list` 는 기념값이 끝난 뒤
실제로 받을 값이어야 합니다. 그럴 뜻이 없으면 `null` 로 두세요 —
줄 그은 값이 사라집니다. 받지 않을 값을 줄 그어 두면 거짓 할인입니다.

한 번 낸 복채는 그 기기의 브라우저에 표로 남습니다. 새로고침해도
다시 받지 않습니다. 사진은 남기지 않으므로 풀이를 다시 보려면
얼굴만 한 번 더 비추면 됩니다.
