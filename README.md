# 백귀관상

원안법사(圓安法師)가 얼굴에 새겨진 기운을 읽어 열두 자리와 올해의 운을 살피는 관상 데모판.

- `index.html` — 화면 전부가 이 한 장에 들어 있습니다. 틀도 빌드도 없습니다.
- `img/` — 키비주얼, 제목 글자, 청동경, 백귀도, 법사 장면, 백귀 100장.

## 흐름

거울 받기 → 나이·성별 → 셀카 또는 사진 → 자세 잡기 → 얼굴 읽기 →
유년운기부위로 과거 적중 → 자국 짚기 → 백귀 셋 중 고르기 →
열두 자리(한 자리만 공개) → 복채 3,990원 → 전부 열람 →
점자리·색·머리 처방 → 백귀도 한 장 → 맺음말·9,900원 안내

## 아직 데모인 부분

- 얼굴을 실제로 분석하지 않습니다. 풀이는 미리 써 둔 것이 나옵니다.
- 결제는 누르면 바로 열립니다.
- 백귀 100장 중 열두 자리에 쓰는 열두 마리만 연결돼 있습니다.
