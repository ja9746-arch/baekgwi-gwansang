# 백귀관상 전면 재구성 — 구조와 화면 1차

## 현재 구현 확인
기존 정적 HTML, 사진 업로드·카메라·자동 위치 맞춤·크기 조절, 로컬 Canvas 판독, 십이궁 좌표, 결과 저장, 결제 데모를 확인했다. 기존 결제는 PG 미연동이며 브라우저에 개봉 표시를 기록하는 데모다.

## 유지 / 수정 / 삭제 / 신규
- 유지: engine.js, gungsang.js, 원본 사진 로컬 처리, 업로드/카메라/드래그/확대, 얼굴 좌표 변환.
- 수정: 처음 입장부터 얼굴 탐색까지의 화면 구성, 원안법사 이미지, 전체 타이포그래피, 짧은 의식, 가격 9,900원.
- 주 흐름에서 제거: 귀신 카드 선택, 과거 적중 문답, 사주 교차 판매. 기존 함수는 회귀 방지를 위해 보존.
- 신규: 무료 3부위/잠긴 영역, 8첩 목차, 전통 문화 해설 패널, 봉인 편지, 인쇄용 관상첩, 얼굴 없는 공유 카드.

## 이번 적용 범위
사용자 요청에 따라 전체 상품의 화면 구조와 제공된 이미지 기반 디자인을 우선 연결한다. 원안법사 투명 WebP 6종을 기능별 배치한다. 사진은 결과 화면에서도 유지한다. 기존 판독 엔진의 길흉/성격 단정은 새 화면에 노출하지 않는다. 현재 장별 내용은 구조 검수용 문화 해설이며 최종 개인별 관찰 보고서가 아니다.
